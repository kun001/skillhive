# MCP 权限与新增写入实施方案

设计确认日期：2026-10-14。本文描述本次实现的权限契约；上线日期以更新日志为准。

## 1. 调用方式

用户创建 Token，AI 客户端调用工具，SkillHive 每次校验身份、操作权限、资源范围与业务权限，通过后直接执行。
不设置待确认任务、网页确认链接或确认中心。客户端自行决定是否请求用户确认；客户端的批准声明不作为服务端权限依据。

远程入口继续使用 `/api/v1/mcp` Streamable HTTP，本地 `mcp/` 使用 stdio。两者最终调用同一组受限后端入口。
不增加 OAuth、设备码登录、ClawHub 或发现端点。

## 2. Token 类型与兼容

- 旧的只读 API Token 可继续使用读取工具，原权限语义不变。
- 旧的发布、删除、Token 管理凭证仍不能用于 MCP，不自动升级。
- 网页新建 Token 默认采用 MCP 授权，携带内部标记 `mcp:access`，必须显式选择操作与命名空间。读取选项即只读权限，不另设只读模式或 MCP 用途切换。
- `resource_grants_json` 保存命名空间 ID 快照，以及可选的知识库 ID 集合。资源 ID 不依赖显示名称。
- 知识库集合为空表示不允许任何知识库；未指定集合表示所选命名空间内、用户当前有权访问的知识库。
- 加入新的团队不会扩大原 Token 的范围。所选命名空间内新增知识库，只有未限定知识库集合的 Token 才能访问。
- Token 只保存哈希，明文仅创建时显示。到期、撤销、账号停用、退出团队、编辑或下载权限撤销影响后续调用。
- 写入 Token 默认 7 天、最长 30 天；修改到期时间也不得改成永不过期或超过 30 天。只读 Token 保持现有期限选项。
- Token 列表的「查看权限」按钮弹出访问范围面板，与创建 Token 共用六项操作布局，并展示已授予的命名空间和知识库；旧版 API 权限按原语义展示，缺失资源名称时保留授权 ID。

## 3. 操作权限

| 领域 | 读取 | 新增上传 | 删除 |
|---|---|---|---|
| 技能 | `skill:read` | `skill:upload` | `skill:delete` |
| 知识文件 | `knowledge:read` | `knowledge:upload` | `knowledge:delete` |

权限独立授予，默认仅技能读取。读取沿用当前元数据、文件内容与下载权限规则，不重新定义已有 `read` 作用域。
没有 `skill:update`、`knowledge:update`，也不提供重命名、改描述、移动、覆盖、追加版本、恢复版本或永久清除工具。

有效权限是 Token 操作权限、Token 资源范围、用户当前业务权限和对象生命周期规则的交集。
团队写入要求实际成员身份和编辑能力；平台管理员身份不能绕过团队成员边界。
公开技能上传还要求现有平台发布角色，但 MCP 上传不使用管理员自动发布能力，继续扫描和审核。

## 4. 工具与后端入口

现有读取工具保留，`tools/list` 根据读取范围提供；调用时重新校验，不依赖客户端缓存。

| 新工具 | 受限后端入口 | 效果 |
|---|---|---|
| `upload_skill` | `POST /api/v1/mcp/skills/{namespace}/uploads` | 上传新技能 ZIP；已有技能名冲突拒绝 |
| `upload_document` | `POST /api/v1/mcp/knowledge/{namespace}/{base}/uploads` | 上传新文件；同目录同名文件拒绝 |
| `delete_skill` | `DELETE /api/v1/mcp/skills/{namespace}/{slug}` | 归档技能，不永久删除存储文件 |
| `delete_document` | `DELETE /api/v1/mcp/knowledge/documents/{documentId}` | 按现有规则归档知识文件 |

技能归档仅允许所有者或团队管理者，知识文件删除沿用文件所有权和团队管理规则。
存在同名多所有者技能时，删除返回不可用/不明确，不猜测目标。

MCP 专用 Token 禁止调用旧的发布、版本修改、永久删除、管理后台、成员管理与 Token 管理接口。
新入口即使被直接通过 REST 调用，也执行相同权限与参数校验；修改 HTTP 方法不会扩大授权。

## 5. 上传和失败处理

- 文件通过 `fileName`、`contentBase64` 提交，单文件最多 10 MiB，不接受下载 URL 或服务器文件路径。
- 技能必须为合法 ZIP，复用现有路径、展开数量、解压大小、结构与安全检查。存在需处理的警告时拒绝，不自动确认。
- 技能新增在领域服务内检查已有对象；同命名空间发布通过数据库行锁串行检查，不能追加版本。
- 知识上传复用现有文件类型、大小、目录归属与对象存储流程；同名检查在知识库行锁内进行。
- 知识文件正式上传后立即发布，不引入内容解析、向量索引、RAG 或新的文件审核流程。
- 目录 ID 必须属于目标知识库。上传只作用于已有目录，不通过 MCP 创建、移动或删除文件夹。

## 6. 幂等与审计

四个写入工具均要求 `idempotencyKey`（1–128 字符）。键绑定具体 Token、操作与规范化参数摘要。
相同请求重试返回原结果；同键不同内容返回冲突。参数摘要包含目标、元数据与文件内容，不保存明文文件副本。
数据库记录与业务变更在同一事务中提交；失败回滚后可重试。记录保留 30 天，清理任务删除过期记录。

成功写入记录操作者、Token ID、操作、摘要、结果和请求上下文。知识文件读取/上传/删除继续保留现有业务审计。
不会记录 Token 明文或文件正文。工具错误不会回显无权资源的上游响应正文。

写入工具标记 `readOnlyHint=false`，删除工具标记 `destructiveHint=true`。这些信息供客户端展示，不替代授权。
远程根入口与受限写入入口均检查 Bearer Token、Origin、协议版本。上传与删除入口复用限流设施。

## 7. 查询范围

命名空间范围在搜索 SQL、个人列表和团队身份投影中应用。知识库范围在列表、跨库搜索、详情与版本访问中应用。
分页前过滤，同时过滤总数；文件内容、历史版本和显式对象 ID 请求也检查同一范围。
不对无权对象提供文件名、所属团队或版本内容。已有只读 Token 的行为保持兼容。

## 8. 验收

- 旧只读 Token 可用；旧读写 Token 仍不能进入 MCP。
- 六种权限独立生效；未授予工具不可调用。
- 管理员 Token 无法跨团队；显式 ID、目录和知识库参数不能混用越权。
- 搜索、列表、分页总数、详情、文件与版本范围一致。
- 新技能拒绝已有名称，知识文件拒绝同目录同名；没有覆盖或修改入口。
- 相同幂等键重试不重复写入，不同参数冲突，并发相同请求只有一次变更。
- 归档不永久删除文件；普通成员不能删除他人内容。
- 撤销、到期、账号停用、退出团队和编辑/下载撤销后，后续调用被拒绝。
- 超大文件、非法 base64、危险路径、恶意压缩包与非法 Origin 被拒绝。
- 远程与 stdio 工具名称、权限、副作用标记一致。
