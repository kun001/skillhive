# 文件夹上传与 MDX

知识库的“上传文件”弹窗增加“选择文件夹”。选择后保留所选顶层文件夹及全部有文件的子目录。在“查看目录并确认”中核对目标位置、目录结构和文件数量，点击“确认并开始上传”才创建文件夹并上传文件。

- 单文件仍不超过 100 MB，格式规则与普通上传一致；MDX 可上传、下载、版本管理，并按纯文本安全预览，不执行 JSX、JavaScript 或导入模块。
- 路径无效、文件重复或存在不支持的文件时，先返回检查并移除问题文件。浏览器的目录选择器无法读取空目录，空目录不会被创建。
- 不自动合并目标位置已有的同名顶层目录；更换上传位置或重命名本地文件夹后重新选择。
- Markdown 引用的图片随正文作为配图保存，同时保留其在上传目录中的独立文件；不把其他子目录图片附到每篇 Markdown。
- 上传按文件逐项发布。部分失败时成功文件和已创建的目录保留，可在当前弹窗重试失败文件；重试复用本次创建的目录，不重复创建成功文件。创建目录后锁定目标位置和文件选择。关闭弹窗后可在知识库继续管理已上传内容。
- 每次建目录、上传文件仍通过现有会话、CSRF、团队成员与编辑权限校验，并记录现有审计日志。没有新增匿名或 Token 写入入口。
