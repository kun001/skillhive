# 项目简介

SkillHive 是团队 Agent 的私有上下文中心：部署在你自己的服务器上，把团队的做法和资料按权限交给成员正在使用的 Agent（Claude Code、Cursor 或自建 Agent 等 MCP 客户端）。它把两类团队资产放在同一个团队空间里：

- **技能库**：可复用的 AI 技能包（`SKILL.md` 格式）。技能上传后经过结构校验、安全扫描和人工审核才会发布，减少带风险的脚本流入团队。
- **知识库**：团队的文件中心。模板、手册、项目资料按文件夹整理，可在线预览、保留版本历史，上传即对有权限的成员可见。

成员打开团队空间，就能同时找到"怎么做"（技能）和"用什么做"（资料）；Agent 通过 MCP 用成员自己的 Token 取用同样的内容，权限逐次校验，读写记入审计。数据全部留在你自己的服务器上。

## 核心特点

| 特点 | 说明 |
|------|------|
| 私有部署 | Docker Compose 或 Kubernetes 部署在自己的服务器或内网，文件存放在本地磁盘、S3 或 MinIO |
| 先审核再发布 | 技能包经过校验、安全扫描和审核后才发布，检索和下载只使用已发布版本 |
| 细粒度权限 | 空间角色（所有者 / 管理员 / 成员）之外，可为每位成员单独设置只读、可编辑与下载权限，调整即时生效 |
| 资料可预览、可回溯 | PDF、图片、Markdown、Word、PowerPoint 在线预览；每次更新都保留版本，可下载或恢复 |
| 不绑定 AI 工具 | 技能采用通用的 `SKILL.md` 格式，下载后交给你习惯的 AI 工具使用；也可以通过只读的 MCP 服务让 AI 工具直接查阅 |
| 可审计 | 发布、审核、权限变更、知识文件下载与预览、通过 Token 读取技能等关键操作都记入审计日志 |

## 边界

- SkillHive 不在平台内执行技能脚本。
- 知识库搜索匹配文件标题、描述、AI 摘要和提取出的正文；不提供向量检索、RAG 问答或扫描件 OCR。
- 知识内容默认不对匿名用户开放；公共技能库中的公开技能可以匿名浏览和下载。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19、TypeScript、Vite、TanStack Router / Query |
| 后端 | Java 21、Spring Boot、Maven 多模块 |
| 数据 | PostgreSQL 16、Redis 7 |
| 文件存储 | 本地磁盘、S3 或 MinIO |
| 安全扫描 | Python（Cisco AI Skill Scanner） |
| MCP 服务 | TypeScript（本地 stdio） |
