# 知识库

## 功能描述

知识库是团队的文件中心：成员在团队空间下的知识库中按多层文件夹整理文件，在线预览、下载，并保留每个文件的版本历史。上传即发布，有权限的成员立即可见。

- 一个团队空间可以有多个知识库，只能建在团队（`TEAM`）类型的空间下
- 多层文件夹，移动时不会形成环
- 批量上传、进度查看与失败重试；Markdown 可连同本地图片或整个文件夹上传
- 每次更新保留版本，可下载或恢复历史版本
- 按标题和描述搜索文件，可跨知识库

SkillHive 会把 Word、PowerPoint、Excel、PDF 和文本文件提取为 Markdown，搜索覆盖标题、描述、AI 摘要和正文；不提供向量检索、RAG 问答、扫描件 OCR 或在线协同编辑。

## 支持的文件

单个文件上限 **100 MiB**。

| 文件类型 | 格式 | 取用方式 |
|----------|------|----------|
| PDF | `.pdf` | 在线预览、下载 |
| 图片 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp` | 在线预览、下载 |
| Markdown / 文本 | `.md`、`.markdown`、`.txt` | 在线阅读；Markdown 可连同图片上传 |
| Word / PowerPoint | `.docx`、`.pptx` | 浏览器内预览、下载 |
| 旧版 Word / PowerPoint | `.doc`、`.ppt` | 上传、下载与版本管理 |
| 表格 / 数据 | `.xls`、`.xlsx`、`.csv`、`.json` | 上传、下载与版本管理 |
| 压缩包 | `.zip`、`.rar`、`.7z` | 上传、下载与版本管理 |

DOCX、PPTX 由浏览器渲染，排版可能与 Microsoft Office 略有差异。

## 权限

| 操作 | 允许的人 |
|------|----------|
| 查看知识库、文件列表 | 团队空间成员 |
| 预览、下载文件内容 | 具备下载权限的成员（空间所有者和管理员始终具备） |
| 上传文件、上传新版本、新建文件夹 | 具备编辑权限的成员 |
| 编辑、移动、删除文件，恢复历史版本 | 文件上传者、空间所有者 / 管理员 |
| 创建、编辑知识库 | 空间所有者 / 管理员 |

知识库不对匿名用户开放。平台超级管理员在网页上可以查看所有团队的知识库，但通过 API Token 访问时只按团队成员身份判断。

预览需要把文件数据传给浏览器，因此下载权限控制的是下载入口和下载接口，无法阻止有预览权限的成员从浏览器提取预览数据。

## 使用步骤

1. **新建知识库**：空间管理员打开「知识库」，在团队空间下新建知识库。
2. **整理文件夹**：在知识库中新建多层文件夹。
3. **上传文件**：拖拽或选择文件批量上传；Markdown 可选择连同其引用的本地图片一起上传。
4. **预览与下载**：点击文件在线预览；有下载权限的成员可下载当前或历史版本。
5. **更新与回溯**：上传新版本时可填写变更说明；在版本历史中下载或恢复任意历史版本。

## 审计

上传、新版本、编辑、删除、恢复、文件夹和知识库变更都写入审计日志。每次获准的下载和预览也会记录，并注明来自网页会话还是哪个 API Token。

## AI 工具访问

持有「知识库（只读）」权限的 API Token 可以通过 `/api/v1/knowledge` 只读访问知识库，也可以配置本地 MCP 服务让 AI 工具直接读取原文件，见 [API Token 与 MCP](/guide/api-token-mcp)。
