# SkillHive

**SkillHive 是面向团队的知识与 SKILL 技能管理平台。** 它以团队空间组织成员和资源，通过 Web 界面完成技能的上传、检查、审核、发布、检索与下载，让可复用的技能在团队内有明确的归属、版本和管理流程。

平台将用户、角色权限、通知和审计放在同一套治理体系中。团队可以管理自己的空间与成员，管理员可以处理审核和安全问题，使用者可以查找并获取已发布的技能。

## 功能

| 能力 | 说明 |
| --- | --- |
| 技能库 | 按名称、团队空间等条件查找技能，查看详情、版本并下载已发布的技能包。 |
| Web 上传与发布 | 上传包含 `SKILL.md` 的技能包，进行包校验和安全扫描，再进入审核与发布流程。 |
| 团队空间与权限 | 使用团队空间组织技能和成员，按平台角色与空间角色控制管理操作。 |
| 审核与治理 | 处理待审核版本、下架或隐藏等管理动作，并保留通知与审计记录。 |
| 知识库 | 团队文件中心：在团队空间下建立知识库，按多层文件夹上传、在线预览（PDF、图片、Markdown、TXT）和下载文件，并保留版本历史。 |

SkillHive 的主要使用路径是：成员在 Web 端上传技能包，平台完成校验与扫描，审核通过后发布到技能库，其他成员再按权限检索和下载。

## 系统组成

| 组件 | 技术与职责 |
| --- | --- |
| `web/` | React、TypeScript、Vite；提供技能库、团队空间、审核与管理界面。 |
| `server/` | Java 21、Spring Boot；承载认证授权、技能生命周期、审核、搜索和 API。 |
| `scanner/` | Python 安全扫描服务，检查上传的技能包。 |
| PostgreSQL、Redis、对象存储 | 分别保存业务数据、会话及缓存、技能文件。对象存储可使用本地文件或 S3/MinIO。 |
