# SkillHive 首页品牌规范

## 核心令牌

```css
:root {
  --bg: oklch(100% 0 0);
  --surface: oklch(97.6% 0.001 286.4);
  --fg: oklch(27.3% 0.025 56.1);
  --muted: oklch(49.5% 0.030 59.4);
  --border: oklch(94% 0 0);
  --accent: oklch(46.7% 0.097 53.9);
}
```

## 字体

- 展示字体：`Iowan Old Style`, `Songti SC`, `STSong`, `SimSun`, `Georgia`, serif
- 正文字体：`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `PingFang SC`, `Microsoft YaHei`, sans-serif
- 等宽字体：`ui-monospace`, `JetBrains Mono`, `SFMono-Regular`, `Consolas`, monospace

## 视觉语言

1. 暖铜色只承担关键动作、当前状态和少量引导信息，不作为大面积背景。
2. 页面以白色为主背景，浅灰仅用于分隔产品演示区与内容层级。
3. 大标题采用高对比宋体气质，正文保持中性无衬线，形成克制的编辑感。
4. 以留白、细分隔线和轻量表面替代密集描边卡片，减少界面噪声。
5. 产品能力优先通过真实名称、用途、版本和流程说明表达，不添加虚构指标。
