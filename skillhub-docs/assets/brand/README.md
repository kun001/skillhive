# SkillHive sharing assets

## GitHub social preview

- **Image:** [social-preview.png](social-preview.png)
- **Editable source:** [social-preview.html](social-preview.html)
- **Dimensions:** 1280 × 640 pixels
- **Background:** opaque, warm off-white
- **Brand:** existing SkillHive logo, dark brown text, and copper accents
- **Interface image:** a still frame from [the skill-library walkthrough](../demos/skill-tour.gif)

To update the cover, serve the repository locally, open the HTML source, and
capture its 1280 × 640 canvas at a device scale factor of 1. The source references
the existing logo in the parent folder and embeds the interface still frame.

To use the image on GitHub, open the repository's **Settings → General → Social
preview → Edit → Upload an image** and select `social-preview.png`.

The cover describes current resource-management capabilities. Keep future
integrations out of the cover until they are available.
